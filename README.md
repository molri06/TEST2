# Canvas Notes

무한 캔버스 위에 생각을 흩뿌려 두는 브레인스토밍 노트 앱.
`docs/project-brief-template.md`의 예시 기획을 그대로 구현한 v1입니다.

## 실행

```bash
npm run dev     # → http://localhost:5173
```

빌드 도구도 의존성도 없습니다. `index.html`을 브라우저에서 직접 열어도 동작합니다.

## 사용법

| 동작 | 조작 |
|---|---|
| 노트 만들기 | 빈 곳 더블클릭 (내용을 안 쓰고 나가면 사라짐) |
| 노트 옮기기 | 노트 테두리를 잡고 드래그 |
| 글자 편집 | 노트 안 텍스트 클릭 |
| 글자 크기 | 노트 선택 후 `A−` / `A+` |
| 노트 삭제 | 노트 선택 후 `✕` 또는 Backspace |
| 캔버스 이동 | 빈 곳 드래그, 또는 트랙패드 두 손가락 |
| 확대 / 축소 | 휠, 또는 트랙패드 핀치 (20%~400%) |
| 이미지 추가 | 이미지 파일을 캔버스에 끌어다 놓기 |
| 노트 안에서 찾기 | 우하단 `검색`, 또는 Ctrl/Cmd + F |
| 웹 검색 | 노트 왼쪽 위 돋보기 배지 클릭 |
| 검색 대상 지정 | 노트 선택 후 `검색` 체크박스 |
| 전체 보기 | 우하단 `화면 맞추기` |
| 사용법 배너 | 우하단 `사용법`으로 다시 열기 |
| 타자 연습 | 우하단 `타자 연습` |
| 타자 연습 2 (떨어지는 낱말) | 우하단 `타자 연습 2` |

화면 맨 위 배너에 조작법이 정리되어 있습니다. `✕`로 닫으면 다음에도 닫힌 채로 열리고,
우하단 `사용법` 버튼으로 언제든 다시 볼 수 있습니다.

각 노트 오른쪽 아래에는 작성 시각(`2026.08.29 14:03`)이 10px로 표시됩니다.
크기는 `src/style.css`의 `.note .stamp` 규칙 한 줄에서 바꿉니다.

편집 내용은 브라우저 로컬 저장소에 자동 저장되어 새로고침해도 유지됩니다.

## 검색과 메모 전용 노트

노트를 선택하면 뜨는 툴바 맨 왼쪽에 **`검색` 체크박스**가 있습니다.

- **체크 켬(기본)** — 검색 결과에 나옵니다.
- **체크 끔** — 메모 전용. 검색에서 제외되고, 노트 왼쪽에 회색 띠가 생겨 한눈에 구분됩니다.

검색 대상 노트는 왼쪽 위에 **돋보기 배지**가 붙어 한눈에 구분됩니다.
배지를 누르면 노트 아래로 `ㄴ` 자 선으로 연결된 카드가 열리고,
카드의 항목을 누르면 그 노트 내용으로 구글·네이버·유튜브 검색이 새 탭에서 열립니다.
노트를 옮기면 선과 카드도 따라옵니다.

노트 안에서 찾는 검색 창에서는 일치한 글자가 강조되고, 해당 노트도 캔버스에서 함께 빛납니다.
결과를 누르면 그 노트가 화면 가운데로 옵니다(Enter는 첫 결과로 이동).
이미지 노트는 본문 텍스트가 없어 검색 대상이 아닙니다.

## 타자 연습 1 · 노랫말 따라 치기

우하단 `타자 연습`을 누르면 노랫말로 타자 연습을 합니다. 창 위쪽에서 곡을 고릅니다.

| 곡목 | 출처 |
|---|---|
| 애국가 (1절·후렴) | 대한민국 국가, 작자 미상 |
| 아리랑 / 새야 새야 파랑새야 / 도라지 타령 | 전통 민요, 작자 미상 |
| 옛 시조 | 정몽주·황진이, 14~16세기 |
| 내 노트 | 캔버스에 적어 둔 내 문장 |

저작권이 소멸한 글만 실었습니다. 요즘 가요 가사는 저작권이 살아 있어 앱에 넣지 않았습니다.
연습하고 싶은 가사가 있으면 노트에 적어 두고 `내 노트`를 고르면 됩니다.
고른 곡은 기억되고, `내 노트`인데 적어 둔 문장이 없으면 애국가로 되돌아갑니다.

- 글자마다 맞으면 흐리게, 틀리면 빨간 물결로 표시되고 현재 위치가 강조됩니다.
- 한 줄을 정확히 입력하면 자동으로 다음 줄로 넘어갑니다.
- 분당 타수와 정확도가 실시간으로 갱신되고, 최고 기록은 저장됩니다.
- 창 위쪽 얼음이 정확히 칠수록 위에서 아래로 녹습니다. 얼음 윗면을 11개 기둥으로 나눠
  자리마다 녹는 속도를 달리 뒀기 때문에 경계가 들쭉날쭉해지고, 판마다 결이 새로 정해집니다.
  맞게 친 글자만큼 녹고,
  틀린 자리 하나당 0.6글자만큼 다시 업니다. 15%에서 금이 가고 물방울이 떨어지며,
  다 녹으면 얼음 속 보물 상자가 드러납니다.
- 얼음덩어리와 보물 상자는 주신 참고 이미지를 보고 SVG로 직접 그렸습니다
  (외부 이미지 파일 없이 코드 안에 들어 있습니다).
- 붙여넣기는 막혀 있습니다. `Esc` 또는 바깥 클릭으로 닫습니다.

정확도는 `맞게 친 글자 ÷ (맞게 친 글자 + 틀린 자리 수)`로 계산합니다.

## 타자 연습 2 · 떨어지는 낱말

우하단 `타자 연습 2`를 누르면 같은 노랫말을 낱말로 쪼개 하늘에서 떨어뜨립니다.
곡목과 얼음·보물 규칙은 타자 연습 1과 같고, 치는 방식만 다릅니다.

- 낱말이 나타나는 **가로 자리도, 떨어지는 속도(5.5~9.5초)도, 나오는 간격(1.1~1.9초)도 매번 다릅니다.**
- 입력한 글자로 시작하는 낱말이 강조됩니다. 여럿이면 가장 아래(가장 급한) 것을 짚습니다.
- 낱말을 끝까지 입력하면 그 낱말이 터지고, 글자 수만큼 얼음이 녹습니다.
- 물에 닿은 낱말은 놓친 것으로 보고 글자 수 × 0.6만큼 다시 얼립니다.
- 한 판은 낱말 18개(노랫말이 짧으면 그만큼)이고, 마지막 낱말이 정리되면 결과가 나옵니다.
- 최고 기록은 타자 연습 1과 따로 저장됩니다.

두 창은 같은 노을 바다 팔레트와 같은 얼음 장면을 씁니다. 얼음 SVG는 한 번만 적어 두고
두 번째 창에서 복제하되, 그러데이션 id가 겹치지 않도록 이름을 바꿔 답니다.

이 창들만 노을 바다 팔레트(크림·살구·산호·청록·하늘·라벤더)를 씁니다.
캔버스는 노트가 주인공이어야 하므로 무채색을 유지합니다.

## 구조

```
index.html         화면 뼈대
src/style.css      스타일 (라이트/다크 자동)
src/main.js        캔버스 뷰, 노트 조작, 드롭 처리, 검색
src/store.js       localStorage 저장/불러오기
scripts/bundle.mjs 위 파일들을 단일 HTML로 합치는 스크립트
```

```bash
node scripts/bundle.mjs   # → dist/canvas-notes.html (파일 하나로 배포할 때)
```

## v1에서 제외한 것

협업, 댓글, 노트 간 연결선, 태그, 내보내기, 계정·동기화.

## 알려진 한계

- 이미지는 data URL로 저장되므로 localStorage 용량(보통 5MB)을 넘으면
  저장에 실패합니다(콘솔 경고). 파일 기반 저장은 v2 과제입니다.
- 캔버스는 하나뿐이고 실행 취소(undo)는 없습니다.
- 노트 안 검색은 단순 부분 문자열 일치입니다(초성 검색·오타 보정 없음).
- 웹 검색은 새 탭을 여는 방식입니다. 결과 제목·요약을 카드 안에 직접 채우려면
  검색 API 키와 이를 중계할 서버가 필요합니다(브라우저에서 구글에 직접 요청하면 CORS로 막힘).
