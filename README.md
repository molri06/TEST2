# Canvas Notes

무한 캔버스 위에 생각을 흩뿌려 두는 브레인스토밍 노트 앱.
`docs/project-brief-template.md`의 예시 기획을 그대로 구현한 v1입니다.

## 실행

```bash
npm run dev     # → http://localhost:5173
```

빌드 도구도 의존성도 없습니다. `index.html`을 브라우저에서 직접 열어도 동작합니다.

## 사용법

| 동작 | 조작 |
|---|---|
| 노트 만들기 | 빈 곳 더블클릭 (내용을 안 쓰고 나가면 사라짐) |
| 노트 옮기기 | 노트 테두리를 잡고 드래그 |
| 글자 편집 | 노트 안 텍스트 클릭 |
| 글자 크기 | 노트 선택 후 `A−` / `A+` |
| 노트 삭제 | 노트 선택 후 `✕` 또는 Backspace |
| 캔버스 이동 | 빈 곳 드래그, 또는 트랙패드 두 손가락 |
| 확대 / 축소 | 휠, 또는 트랙패드 핀치 (20%~400%) |
| 이미지 추가 | 이미지 파일을 캔버스에 끌어다 놓기 |
| 노트 안에서 찾기 | 우하단 `검색`, 또는 Ctrl/Cmd + F |
| 웹 검색 | 노트 왼쪽 위 돋보기 배지 클릭 |
| 검색 대상 지정 | 노트 선택 후 `검색` 체크박스 |
| 전체 보기 | 우하단 `화면 맞추기` |
| 사용법 배너 | 우하단 `사용법`으로 다시 열기 |

화면 맨 위 배너에 조작법이 정리되어 있습니다. `✕`로 닫으면 다음에도 닫힌 채로 열리고,
우하단 `사용법` 버튼으로 언제든 다시 볼 수 있습니다.

각 노트 오른쪽 아래에는 작성 시각(`2026.08.29 14:03`)이 10px로 표시됩니다.
크기는 `src/style.css`의 `.note .stamp` 규칙 한 줄에서 바꿉니다.

편집 내용은 브라우저 로컬 저장소에 자동 저장되어 새로고침해도 유지됩니다.

## 검색과 메모 전용 노트

노트를 선택하면 뜨는 툴바 맨 왼쪽에 **`검색` 체크박스**가 있습니다.

- **체크 켬(기본)** — 검색 결과에 나옵니다.
- **체크 끔** — 메모 전용. 검색에서 제외되고, 노트 왼쪽에 회색 띠가 생겨 한눈에 구분됩니다.

검색 대상 노트는 왼쪽 위에 **돋보기 배지**가 붙어 한눈에 구분됩니다.
배지를 누르면 노트 아래로 `ㄴ` 자 선으로 연결된 카드가 열리고,
카드의 항목을 누르면 그 노트 내용으로 구글·네이버·유튜브 검색이 새 탭에서 열립니다.
노트를 옮기면 선과 카드도 따라옵니다.

노트 안에서 찾는 검색 창에서는 일치한 글자가 강조되고, 해당 노트도 캔버스에서 함께 빛납니다.
결과를 누르면 그 노트가 화면 가운데로 옵니다(Enter는 첫 결과로 이동).
이미지 노트는 본문 텍스트가 없어 검색 대상이 아닙니다.

## 구조

```
index.html         화면 뼈대
src/style.css      스타일 (라이트/다크 자동)
src/main.js        캔버스 뷰, 노트 조작, 드롭 처리, 검색
src/store.js       localStorage 저장/불러오기
scripts/bundle.mjs 위 파일들을 단일 HTML로 합치는 스크립트
```

```bash
node scripts/bundle.mjs   # → dist/canvas-notes.html (파일 하나로 배포할 때)
```

## v1에서 제외한 것

협업, 댓글, 노트 간 연결선, 태그, 내보내기, 계정·동기화.

## 알려진 한계

- 이미지는 data URL로 저장되므로 localStorage 용량(보통 5MB)을 넘으면
  저장에 실패합니다(콘솔 경고). 파일 기반 저장은 v2 과제입니다.
- 캔버스는 하나뿐이고 실행 취소(undo)는 없습니다.
- 노트 안 검색은 단순 부분 문자열 일치입니다(초성 검색·오타 보정 없음).
- 웹 검색은 새 탭을 여는 방식입니다. 결과 제목·요약을 카드 안에 직접 채우려면
  검색 API 키와 이를 중계할 서버가 필요합니다(브라우저에서 구글에 직접 요청하면 CORS로 막힘).
